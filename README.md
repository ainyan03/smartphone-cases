# Smartphone Cases

3D-printable smartphone cases. Each folder holds one model with its own README, print files (3MF / STL) and photos.

3D プリンタで刷るスマートフォンケースです。機種ごとのフォルダに、説明 (README)・印刷用のファイル (3MF / STL)・写真があります。

| Model | Folder | Notes |
|---|---|---|
| Galaxy Z Fold7 | [galaxy-z-fold7](galaxy-z-fold7/) | Hinge-integrated full case, print-in-place. Camera guard and MagSafe holder included. |

## Releases

Each model is released with a tag named `<folder>-v<version>` (e.g. `galaxy-z-fold7-v1.0`). The release page has a zip of that model's files.

機種ごとに `<フォルダ名>-v<版>` のタグ (例: `galaxy-z-fold7-v1.0`) でリリースし、その機種のファイルをまとめた zip を添付します。
